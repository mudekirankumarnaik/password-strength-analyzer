# Password Strength Analyzer 🔐

A Python-based Cyber Security project that analyzes password strength and demonstrates basic cryptography concepts using SHA-256 hashing.

## Features

✅ Password strength analysis  
✅ Uppercase and lowercase checking  
✅ Number validation  
✅ Special character detection  
✅ Password security score system  
✅ Strong password generator  
✅ SHA-256 password hashing  
✅ Security improvement suggestions  

---

## Technologies Used

- Python
- Regular Expressions (re module)
- SHA-256 Hashing
- Random & String modules

---

## How It Works

The program checks:
- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Common password usage

It then:
- Calculates a security score
- Displays password strength
- Suggests improvements
- Generates a secure sample password
- Converts the password into SHA-256 hash format

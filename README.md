# Password Strength Analyzer 🔐

A Python-based project that checks password strength using:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Password length

## Features
✅ Password strength analysis  
✅ Security score system  
✅ Suggestions for stronger passwords  
✅ Strong password generator  

## Technologies Used
- Python
- Regex (re module)
